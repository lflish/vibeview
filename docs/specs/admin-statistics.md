# 管理统计 v1

状态：已实现，本地验收与 TX 发布验证通过。日期：2026-10-12。

## 目标与范围

在 `/admin/statistics` 提供真实管理统计，对应 [交互设计](../../designs/admin-statistics.html)。第一版包括今日上传、所选范围上传、当前文件数/体积、每日趋势、月历、按日分页记录、类型分布、来源排行和上传/删除活动。支持近 7 天、近 30 天、本月及来源/类型筛选，沿用管理端浅色/深色/跟随系统主题。

本版不实现浏览量、访客追踪、存储配额编辑、定时报告、统计导出或上传账户的统计权限。上传 CLI 和访问码协议保持兼容。

## 统计口径

| 指标 | 定义 |
| --- | --- |
| 今日上传 | 配置时区当天 00:00 到响应 `asOf` 的成功上传，显示昨日全天作为参考，不把今日未结束的值算成完整日环比 |
| 范围上传 | 包含首尾日期的成功上传数量及字节数；后来删除文件不减少累计上传 |
| 当前文件/体积 | 仍保留的元数据记录及其文件字节数，跟随来源/类型，不受统计日期范围影响；不等于服务器磁盘占用 |
| 期间删除 | 在所选日期范围内完成的删除，区分管理员、上传账户和到期清理；与上传发生日期独立 |
| 月历 | 所显示月份的每日上传，跟随来源/类型；不受上方趋势时间范围影响；无上传显示 0，未来日期不可选择 |
| 日明细 | 当日上传事件，显示当前是否保留；已删除文件隐藏名称，上传记录仍在；每页最多 100 条 |

默认 `statistics.timezone: Asia/Shanghai`，允许有效的 IANA 时区（含夏令时），日期按服务端统一分组。日期参数严格验证，不依赖浏览器或执行主机时区。范围最多 366 天，不允许倒序、无效日期或未来日期；类型只接受 html/image/video。所有空日期补零，不用浏览器当前时间推断“今天”。

## 权威数据、回填与恢复

资源 JSON 仍是现存文件的权威来源，SQLite 仍是可重建的资源列表索引。独立统计日志保存到 `statistics.directory`（缺省为 meta 目录旁的 `statistics/`），不随索引重建、代码发布或文件删除被清空。第一版在主服务内缓存最小事件，启动加载一次；请求不重复扫描所有事件文件或文件内容。要求单个主服务进程，当前 PM2 部署符合此约定。

事件仅包含资源 ID、类型、字节数、来源、事件时间、上传回填标识、删除原因。日志不保存文件名、简介、文件内容、访问码、访问策略/哈希、口令或上传 token。保留文件名仅从现存资源元数据读取。日志文件权限 600，目录权限 700。

首次启动记录 `startedAt`，现存资源以原始 `createdAt` 幂等回填。缺失/无效创建日期不编造时间，展示跳过数量。标明开始记录前及启动当天的历史可能不完整；`completeFromDate` 为启动时间在配置时区的下一天。重启、权限修改和重复删除不重复计数。历史中已删除的来源仍可筛选。

文件系统操作与日志通过预写意图协调：

1. 新上传在提交元数据前持久化最小上传意图；元数据原子重命名为提交点。失败上传撤销意图，不计数。
2. 上传提交后将意图移至事件日志；进程在二者之间退出，启动根据元数据是否存在完成或撤销。若文件随后已被删除，删除事件或删除意图同样可证明上传曾提交，恢复时仍保留该上传记录。
3. 删除前先持久化意图，再删除文件/元数据，最后移至删除日志；中断时启动继续已授权的删除。
4. 提交后的日志移动失败保留持久化意图并更新进程缓存，不向客户端把已提交上传误报为失败。重启恢复该意图。
5. 无法读取日志、恢复删除或写入意图时明确报错，不把缺损历史伪装成零统计；意图写入失败不能开始删除。统计目录必须持久化备份。

## HTTP 接口

所有接口要求管理员 session、返回 JSON 和 `Cache-Control: no-store`；未登录返回 401，非法输入返回 400。上传 Bearer token 不授予管理统计权限。

- `GET /admin/api/statistics?from=YYYY-MM-DD&to=YYYY-MM-DD&month=YYYY-MM&source=&type=`：默认近 30 天/当月；可用 `range=7|30|month` 让服务端计算当前范围，明确 from/to 时以日期为准。返回 timezone/asOf/today、filters、coverage、summary、daily、calendar、types、sources、availableSources、activities / deletionActivities（各自最近 8 条）。
- `GET /admin/api/statistics/day?date=YYYY-MM-DD&source=&type=&page=1&pageSize=20`：返回当日 count/bytes/retainedCount、items、total/page/pageSize/totalPages；事件时间保持 ISO，显示使用响应时区。

API 不返回 token、密码、访问码或访问哈希。已删除记录的 filename 为 null。分页稳定按上传时间、ID 倒序。

## 页面行为

资源管理增加统计入口，统计页可返回资源/账户管理。查询加载时显示加载状态；失败展示可重试错误，401 提示重新登录；不继续展示旧筛选的统计。快速切换筛选只接受最新响应。范围/来源/类型一起影响概览、趋势、分布和来源；月历独立月份但共享来源/类型。点击趋势柱同步月历与当日明细；点击月历只更改当日选择。按日弹窗支持分页，弹窗焦点回到触发按钮，Escape 关闭，键盘可选择趋势和日期。

口径弹窗解释历史回填及统计开始时间；页面持续显示历史覆盖信息。零数据、历史无效日期、未配置 token、删除后来源保留均应正常显示。支持 390px 手机至桌面，无页面横向溢出；共享主题偏好、键盘焦点、减少动画。

## 验收

- 实际上传增加一次；失败上传、访问码修改、重启和索引重建不额外增加。
- 管理员/账户/批量/到期删除减少存量，保留上传数，分别记录删除原因。
- 首次回填、重复启动、重启恢复上传/删除中断，结果幂等。
- 北京时间零点与 IANA 夏令时分日正确，零日期补齐，未来/非法/超长范围拒绝。
- 类型/来源/日期聚合一致，今日和存量不被所选历史范围误筛掉。
- 未登录/只有上传 token 不能获取任何统计，删除项不返回文件名，持久化日志无敏感字段。
- 浏览器验证筛选、月历/趋势联动、明细分页、过期 session、失败重试、旧响应隔离、主题及手机布局。
- 双语指南、配置示例、deploy-tx/dview-upload Skill 与实际接口一致；验证使用隔离数据。

## 发布与回滚

提交、推送和生产发布需要用户授权。发布时冻结运行时代码，备份资源元数据与独立统计日志，保留服务器配置和数据；回滚只恢复代码。运行老版本期间的操作可能不产生统计事件，因此不能宣称该期间完整覆盖。迁移和恢复在清理任务之前运行。Sidecar 不写统计日志，常规健康检查不足以证明统计正确，需要测试临时上传/删除及重启后的不变性。
