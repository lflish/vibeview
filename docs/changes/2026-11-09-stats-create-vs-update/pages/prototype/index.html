      统计口径（新增部分）

      新建改名
      第一次上传，生成一个新链接。原来的“上传”指的就是它。
      更新新增
      给已有链接上传新版本（同一路径再次上传、--id、模板重新渲染）。改访问码、分类、简介，删除历史版本，都不算。
      上传
      新建 + 更新。删除资源或历史版本后，已记下的新建和更新都不减少。
      历史更新
      上线时从资源保留的版本回填；被保留上限清理掉的版本、上线前已删除资源的更新无法还原。

      在终端回复关口 A 即可，这一页不需要操作。
