c3. 隐私验收（R5.1）的写法要改一下吗？

原来写的是“统计接口返回里找不到文件名”。但统计页本来就会显示仍保留资源的文件名（已删除的才隐藏），照字面验收会失败。

建议改为：统计日志里不含文件名、简介、访问码、token；统计接口不含 token、简介、访问码和访问哈希；仍保留的资源照旧显示文件名。

推荐：按建议改

方案要点

问题做法
怎么发现一次更新写元数据时，当前版本号没记过就记一次；改访问码、分类、删历史版本时版本号不变，不记
崩溃了怎么办先写意图，元数据落盘才算数；重启时有元数据就补记，没有就丢弃

接口兼容只加字段：created、updated、uploadKind、version；count 改为合计
页面卡片、趋势图（两段柱）、月历、当日明细、最近活动、分布和排行都分开显示
