# 预览和访问码

## 子功能

- 上传默认带访问码；`--public` 或 `PATCH .../access {"mode":"public"}` 改为公开
- 预览页 `/v/<id>`：未验证时显示访问码表单；验证成功后用 cookie 访问；访问码过期后提示过期，文件保留
- 访问码错误多次被限流

## 怎么到达

浏览器打开 `$BASE/v/<id>`；接口 `PATCH /api/me/items/:id/access`（token）或管理端资源页。

## 怎么操作和验证

1. 上传后不带 cookie 打开 `/v/<id>` → 看到访问码表单，看不到页面内容。
2. 输入 `accessCode` 提交 → 跳回预览，看到页面内容；刷新仍可见。
3. 输入错误访问码 → 提示错误，内容不可见；连续错误后提示被限流。
4. 改为公开后，新开 context 直接可见。

## 注意事项

- 访问码只在上传响应里返回一次（管理端可查看）；不要把访问码写进 URL 或证据文件名。
- 预览页的 HTML 在沙箱里运行，不能调用管理接口（`npm run test:templates` 里有对应断言）。
