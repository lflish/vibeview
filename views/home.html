BUILT FOR AGENTS

让 agent 做的页面，越改越好用。

需求反复改、账单每月出，链接和版式都不用重来。

需求改十版，链接还是那一个

同一个文件再上传，就是同一个链接的新版本，访问码不变。评审的人刷新一下就是最新版，也能翻回任意一版对照。

-m "改了什么" · .dview.json 记住路径 · /v/<id>/@3

模板：版式固定，agent 只填数据

账单、周报这类固定版式的页面，agent 只整理数据，由模板校验和渲染，合计也由模板计算。同样的数据，每次出来一模一样。

打印 · 导出 Excel 按模板开启 · 数据一律转义

一句话，触发对应的模板

每个模板可以生成一个配套 skill。对 agent 说"给 A 供应商出 10 月账单"，它直接用账单模板，不用你记模板名字。

dview template skills sync

GET STARTED

从本地文件，到分享链接。

先准备服务地址和上传 token，再把文件交给 vibeview。

  1. 01

    生成或准备文件

    一个 HTML 报告，一张截图，或一段演示视频。

  2. 02

    用 /dview、CLI 或 curl 上传

    在 Claude Code 里说一句 /dview 就能生成并上传；其他 agent 读仓库里的 AGENTS.md。上传 token 由管理员配置。

  3. 03

    分享链接与访问码

    保存 JSON 响应中的链接、访问码和到期时间，即可在浏览器预览。

export DVIEW_URL="https://view.example.com"
export DVIEW_TOKEN="你的上传 token"

# 在本项目目录中执行
bash bin/dview upload ./report.html --json
